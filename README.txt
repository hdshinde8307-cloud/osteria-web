ÒSTERIA WEBSITE — IMAGES TO UPLOAD
====================================

This site now uses plain image files instead of embedded photos, so you can
drop in your own JPGs/PNGs from Instagram (or new photography) at any time
without touching the code.

HOW TO ADD IMAGES
------------------
1. Create a folder named "images" in the same folder as index.html and menu.html
   (it should already exist here, alongside this file).
2. Save each photo using the EXACT filename listed below (lowercase, with the
   .jpg extension) into that "images" folder.
3. Refresh the page — the photo will appear automatically. No code changes needed.

Until a file is added, that spot will just show a plain warm-beige box — the
site won't break, it just won't have a photo there yet.
